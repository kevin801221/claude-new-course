多合一卡帶熱插拔 ‧ Skills + Agents + Hooks + MCP 整包發布 ‧ 跨團隊共享

外掛展示卡帶：
💡 教學心法：遊戲機「多合一遊戲卡帶 (Game Cartridge)」模型 學生一聽就懂的比喻

告訴學生：我們前幾章學的 Skills (技能)、Subagents (子代理)、Hooks (安檢門)、MCP (資料庫連線)，如果每到一個新專案都要手動設定一次，會非常繁瑣。 Plugin 就是「卡帶」！把這四種能力打包進一個資料夾與 plugin.json，只要一鍵插上 (Install Plugin)，整套企業級工作流立刻原地解鎖！

📁 外掛標準目錄結構 (Package)

Standard

一個合法的外掛只需具備標準子資料夾：

pr-review/
├── .claude-plugin/
│   └── plugin.json       # 外掛元資料身分證
├── agents/               # 專用子代理 (Subagents)
├── commands/             # 快捷指令 (Slash Commands)
├── hooks/                # 專用生命週期攔截器 (Hooks)
└── mcp/                  # 內嵌 MCP 伺服器設定
✨ 結構完全模組化，發布到 npm 或 GitHub 就能分享給全世界工程師！

外掛架構解說 [All-In-One Solution]

Plugin 是 Claude Code 最強大的分發機制。它不是單一功能的腳本，而是一整個解決方案的封裝！

1. 身分清單 (plugin.json)

.claude-plugin/

定義外掛名稱、版本與授權協議：

{
  "name": "pr-review",
  "version": "1.0.0",
  "description": "完整的 PR 審查工作流程，涵蓋安全性、測試與文件",
  "author": { "name": "Anthropic" },
  "license": "MIT"
}

2. 自動掛載 Hooks (hooks.json)

hooks/

安裝外掛時，這些安檢門會自動生效：

{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [{ "type": "command", "command": "./hooks/security-check.sh" }]
      }
    ]
  }
}

3. 一鍵安裝指令 (Install CLI)

Terminal

學生或團隊成員只需一行指令：

# 本機專案安裝
claude plugin add ./plugins/pr-review

# 從 GitHub 遠端倉庫一鍵安裝
claude plugin add github.com/anthropic/claude-plugins/pr-review

# 驗證已載入的外掛
claude plugin list
