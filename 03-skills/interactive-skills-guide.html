提問關鍵字演練：
💡 教學心法：特務裝備庫與「漸進式揭露 (Progressive Disclosure)」 學生一聽就懂的比喻

告訴學生：如果一個工程師每次出門上班，都把 50 本厚厚的百科全書背在身上，他會累死（Token 瞬間爆滿，反應極慢且昂貴）。 Skills 的精妙之處在於「漸進式揭露」：平時 Claude 只記住一張「武器目錄名片 (Frontmatter，僅 50 Tokens)」。 只有當使用者提出相關需求時，雷達一嗶，才把真正的專業手冊 (SKILL.md) 動態空投進大腦！

⚡ Token 消耗與記憶體奇蹟

節省 96%
傳統作法：所有技能全載入 45,000 Tokens (浪費且慢)
Skills 機制：漸進式揭露 (動態載入) 180 Tokens (初始索引)

初始階段只載入技能簡介名片，幾乎零成本！

🎯 給學生的核心結論：不要把所有規則都硬塞在 CLAUDE.md！善用 Skills，平常不花 Token，要用時才由 AI 自行判斷調閱！

階段 1：待命掃描 [Progressive Disclosure]

使用者在終端機輸入請求。Claude Code 的內建雷達會先比對使用者的問題與各個技能的 description 簡介。

1. 使用者提示詞 (Prompt)

User Input

使用者不需要記得指令，只需自然表達意圖：

"請幫我全面審查 src/auth/jwt.ts 這個檔案，特別注意安全性漏洞與函式長度！"
🔑 關鍵字被雷達偵測到：「審查」、「安全性漏洞」！

2. 技能元資料 (Frontmatter)

SKILL.md 標頭

平時僅將此 YAML 摘要保留在記憶體中：

---
name: code-review-specialist
description: 全方位程式碼審查，涵蓋安全性、效能與品質分析。使用時機：使用者要求審查程式碼、分析品質，或提到程式碼審查、安全性分析。
---
🧠 Claude 就是靠這段 description 來決定何時「自動裝備」！

3. 動態空投手冊 (Full Skill Body)

動態裝備到上下文

命中需求後，完整操作指引才正式進駐大腦：

# 程式碼審查專業技能 (已成功載入)

你現在必須依據以下清單逐一檢查目標檔案：
1. 【安全性】JWT 密鑰是否硬編碼？是否有防護 Timing Attack？
2. 【效能】迴圈內是否有重複計算？
3. 【品質】函式長度超過 40 行者必須標記建議重構！
4. 格式化輸出標準 Markdown 報告表格。
✨ 任務完成後，不留多餘垃圾，保持 Claude 思考敏捷！
