# `_Context/` 是什麼？先讀這頁再點別的

> **一句話**：這個資料夾裡的檔案是**AI 之間的工作文件**，不是教材。
> 新手照 `../WALKTHROUGH.md` 走就夠了，這裡可以先不看。

## 為什麼會有這個資料夾？

這個專案是「五個 AI 角色分工蓋出來的」。五個人要平行做事，就得先有共同的白紙黑字：
誰負責什麼、資料長什麼樣、接口怎麼接。這些文件就是那些白紙黑字。

**它們寫得很密，因為讀者是 AI**——AI 不會抱怨句子太長，但會因為少一個欄位名就接錯。

## 三個最常被問的問題

### Q1：「為什麼這兩個角色不能合併？」是什麼意思？

`DESIGN.md` 裡每個角色下面有一段解釋「**為什麼這個角色不能跟別人合併成同一個**」。

背後的道理只有一句：**球員不能兼裁判。**

舉例：

- 「訓練模型的人」如果同時是「打分數的人」→ 他會挑分數最漂亮的那一刻收手，然後說「你看我進步了」
- 「做出正確答案的人」如果同時是「打分數的人」→ 他會把正確答案調成剛好能過
- 「決定什麼時候停的人」如果同時有技術立場 → 他會偏袒自己提的方法

所以這五個角色是**刻意互相牽制**的，不是隨便拆的。

（原本這段的標題寫「為什麼不能跟隔壁合併」，「隔壁」指的是**表格裡相鄰的其他角色**，寫得不清楚，已經改掉。）

### Q3：我現在按前端那顆按鈕，真的會訓練嗎？

**不會。** 現在只到 M1。

按下去只有兩件事：**照片一張一張進來** → **用純幾何自動畫框**。

沒有模型、沒有 PyTorch（專案根本沒裝）、沒有 GPU、沒有 LLM 呼叫、不用網路。
右邊 11 格裡 8 格是灰的「未實作（M2+）」。

真的會訓練要等 **M3**。詳見 `../WALKTHROUGH.md` 最上面那張表。
