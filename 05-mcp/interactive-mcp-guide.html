💡 教學心法：AI 界的「USB-C 統一轉接頭」模型 學生一聽就懂的比喻

以前 AI 要連資料庫、連 GitHub、連 Slack，每家都要寫一套特規 API 程式碼。而 MCP (Model Context Protocol) 就是 Anthropic 提出的「AI 界 USB-C 標準」！ 只要外部服務提供一個 MCP Server，Claude 透過標準的 JSON-RPC 2.0 協定插上去，就能秒懂對方有哪些工具，並直接安全調用！

握手第 1 步：協商初始化 [Protocol Handshake]

Claude Code 啟動時，會根據設定檔自動啟動 MCP Server 行程，並透過 STDIO 發送第一包 initialize 封包，確認雙方的協定版本與能力！

1. MCP 設定檔 (settings.json)

專案設定

告訴 Claude Code 去哪裡啟動對應的伺服器：

{
  "mcpServers": {
    "database": {
      "type": "stdio",
      "command": "npx",
      "args": ["@modelcontextprotocol/server-postgres"],
      "env": {
        "DATABASE_URL": "postgresql://user:***@localhost:5432/app"
      }
    }
  }
}
🔑 只要在 JSON 設定好指令，Claude Code 就會以子行程自動拉起！

2. 請求封包 (Request)

initialize

Claude 發送到 stdin 的標準 JSON-RPC 2.0 格式：

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {
    "protocolVersion": "2024-11-05",
    "capabilities": {
      "roots": { "listChanged": true },
      "sampling": {}
    },
    "clientInfo": {
      "name": "claude-code",
      "version": "1.0.0"
    }
  }
}
📡 嚴格遵循標準協定，任何語言寫的 Server 都能無縫解析！

3. 回應封包 (Response)

Server 回傳

MCP Server 在 stdout 回傳的工具定義或查詢結果：

{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "protocolVersion": "2024-11-05",
    "capabilities": {
      "tools": { "listChanged": false },
      "resources": {}
    },
    "serverInfo": {
      "name": "postgresql-mcp-server",
      "version": "0.1.0"
    }
  }
}
🎉 握手成功後，Claude 就正式解鎖了全新的外部超能力！

🛠️ 1. Tools (動態可調用工具)

AI 可以主動執行的函式，例如 query_database 或 create_github_issue，具備清楚的 JSON Schema 參數規範。

📄 2. Resources (唯讀數據資源)

類似檔案系統或資料庫表格的直接快照，透過 URI 存取（例如 postgres://users/schema），供 AI 隨時查閱背景知識。

💬 3. Prompts (預設提示範本)

伺服器自帶的結構化工作流程提示詞（Slash Commands），讓使用者能一鍵執行該伺服器的專屬最佳實踐。
