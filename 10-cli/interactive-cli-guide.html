CLI (命令列大師與無頭批次自動化) 教學台

不開介面的全自動化 (Headless) ‧ Unix 管道管線串接 ‧ CI/CD 批次處理

💡 教學心法：自動化「無人黑燈工廠 (Lights-Out Automation)」模型 從單兵作業躍升至流水線

跟學生說：如果你只會開著終端機跟 Claude 一句一句聊天，你只發揮了它 20% 的價值。 真正頂級的工程師，是把 Claude Code 嵌入到腳本與 CI/CD 流程中！ 使用 claude -p "..." 搭配 Unix 管道符號 |，下班後讓它自動掃描 100 個 PR、修復所有 Lint 錯誤並寫出報告，完全不需人類動手！

管道輸送帶流程 (Unix Pipeline Automation)

無頭模式 (Headless / Non-Interactive)
📄
Step 1: 資料來源

git diff 或檔案內容

git diff origin/main
⚡
Step 2: 管道串接 (Pipe)

Claude Headless 核心運算

| claude -p "產出資安審查報告"
不跳對話視窗，全自動執行
📊
Step 3: 產物輸出

直接寫入檔案或 PR 評論

> security-report.md
⚙️
無頭自動化演示 [Batch Processing]

透過這條指令，CI/CD 每次有新 PR 時會自動呼叫 Claude 進行資安掃描，並在 30 秒內將乾淨的 Markdown 報告貼在 GitHub 上！

1. 單行管道指令 (Pipe)

CLI One-Liner 
# 審查當前分支的所有改動並寫入檔案：
git diff main | claude -p \
  "依據 Clean Code 原則審查此 diff，列出問題" \
  > review-output.md

# 或是批次修復語法錯誤：
cat errors.log | claude -p \
  "分析此報錯日誌，直接修改對應原始碼修正它"

2. 批次處理腳本 (Batch Script)

batch.sh 
#!/bin/bash
# 批次為所有 .ts 檔案加上 JSDoc 文件
for file in src/**/*.ts; do
  echo "正在為 $file 生成文件..."
  claude -p "為 $file 裡面的匯出函式補上繁體中文 JSDoc 註解" \
    --allowed-tools Edit,Write
done
echo "全部處理完成！"

3. CI/CD 整合 (GitHub Action)

.github/workflows/ 
- name: Claude AI PR Review
  env:
    ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
  run: |
    npm install -g @anthropic-ai/claude-code
    claude -p "審查此 PR 的安全性與測試覆蓋率" \
      --output-format json > pr-comment.json
