SESSION_INIT

SessionStart

— 工作階段啟動與環境準備

執行 session 前置依賴檢查，只在啟動時執行一次 (once: true)

once: true

觸發規格與特性

  • 觸發時機：使用者在終端機輸入 claude 進入對話的一瞬間觸發。
  • 阻擋限制：此事件不支援阻擋工作階段（exit 2 僅發出警告，不中斷對話）。
  • 逾時時間：預設為 600 秒（建議搭配輕量腳本於 2 秒內完成）。

實戰核心用途

  • 檢查本地開發環境（如 Prettier、Git、Docker、Node 是否已安裝）。
  • 通知團隊工作階段啟動（透過 Webhook 送出訊息至 Slack/Discord）。
  • 初始化審計日誌目錄（.claude/hooks/audit.log）。
.claude/settings.json 
{
  "hooks": {
    "SessionStart": [
      {
        "matcher": "*",
        "hooks": [
          {
            "type": "command",
            "command": "./06-hooks/dependency-check.sh",
            "once": true,
            "timeout": 15
          }
        ]
      }
    ]
  }
}
06-hooks/dependency-check.sh (chmod +x) 
#!/bin/bash
# 檢查工作環境相依性工具
LOG_DIR="${CLAUDE_PROJECT_DIR:-$(pwd)}/.claude/hooks"
mkdir -p "$LOG_DIR"

echo "[$(date '+%Y-%m-%d %H:%M:%S')] Session starting..." >> "$LOG_DIR/session.log"

# 檢查關鍵工具
MISSING_TOOLS=()
for tool in prettier git node; do
  if ! command -v "$tool" &> /dev/null; then
    MISSING_TOOLS+=("$tool")
  fi
done

if [ ${#MISSING_TOOLS[@]} -gt 0 ]; then
  echo "警告：系統缺少以下推薦工具：${MISSING_TOOLS[*]}" >&2
fi

exit 0

PROMPT_GATE

UserPromptSubmit

— 提問送出審核與 Context 注入

送交模型前攔截 Prompt、敏感詞過濾或計算提問前 Token 基準

timeout: 30s

觸發規格與特性

  • 觸發時機：使用者按下 Enter 送出提示詞，但在 Claude Code 送交 API 之前。
  • 逾時預算：系統預設自動降至 30 秒，避免讓使用者枯等。
  • 阻擋能力 (Exit 2)：支援！若回傳 exit 2，提問立即被拒絕，完全不消耗 LLM Token。

與 context-tracker.py 的連動

本專案的 context-tracker.py 正是在這個時間點抓取 transcript_path，先將目前對話歷史的 Token 估算值存入暫存檔，為後續回答後的差值計算做準備。

06-hooks/validate-prompt.sh 
#!/bin/bash
# 提示詞敏感資安關鍵字過濾
INPUT=$(cat)
PROMPT=$(echo "$INPUT" | sed -n 's/.*"prompt"[[:space:]]*:[[:space:]]*"\([^"]*\)".*/\1/p')

# 檢查是否含有敏感外洩指令
if [[ "$PROMPT" =~ "AWS_SECRET" || "$PROMPT" =~ "PRIVATE_KEY" ]]; then
  echo "【資安政策攔截】提問內容涉及機密金鑰外洩，已被拒絕！" >&2
  exit 2 # 阻擋提問
fi

exit 0

CRITICAL_GATE

PreToolUse

— 工具調用前審查（支援 Exit 2 阻擋）

海關安檢門：審查即將調用的 Bash 指令或修改路徑，防止毀滅性改動

放行 (Exit 0)

Matcher 模式與比對規則

  • matcher: "Bash"：僅攔截 Bash 指令。
  • matcher: "Write|Edit"：攔截檔案編輯寫入。
  • if: "Write(.env*)"：利用 if 語法更精準鎖定特定引數與路徑。

Exit Code 核心鐵律 (講課必考)

  • exit 0：放行執行工具。
  • exit 2：唯一能阻擋工具執行的狀態碼！Claude Code 收到 exit 2 時，會立刻取消調用該工具，並將導向到 stderr（即 >&2）的文字傳回給模型作為阻擋原因！
.claude/settings.json 
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "$CLAUDE_PROJECT_DIR/06-hooks/pre-tool-check.sh"
          }
        ]
      }
    ]
  }
}
06-hooks/pre-tool-check.sh 
#!/bin/bash
# PreToolUse 安全檢查腳本
INPUT=$(cat)
COMMAND=$(echo "$INPUT" | sed -n 's/.*"command"[[:space:]]*:[[:space:]]*"\([^"]*\)".*/\1/p' | head -1)

# 高危險指令比對
if [[ "$COMMAND" =~ rm[[:space:]]+-rf || "$COMMAND" =~ push.*--force ]]; then
  echo "【安全攔截】偵測到危險指令：$COMMAND" >&2
  echo "禁止透過 AI 自動執行刪除整包目錄或強制推送！" >&2
  exit 2 # 關鍵：exit 2 強制阻擋！
fi

exit 0 # 安全放行

  "tool_input": {

  }
}

POST_ACTION

PostToolUse

— 工具執行後自動處置

寫檔後自動調用 Prettier 原地格式化排版，或記錄執行 audit log

Auto-Format

PostToolUse 無法取消已發生的修改，但它是落實「程式碼自動保潔 (Code Cleanliness)」的殺手鐧功能。 Claude 在產生程式碼時偶爾縮排不一，透過在 PostToolUse 綁定 Prettier，使用者甚至感覺不到排版過程，檔案就被原地格式化整齊了！

.claude/settings.json 
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "./06-hooks/format-code.sh"
          }
        ]
      }
    ]
  }
}
06-hooks/format-code.sh 
#!/bin/bash
INPUT=$(cat)
FILE=$(echo "$INPUT" | sed -n 's/.*"file_path"[[:space:]]*:[[:space:]]*"\([^"]*\)".*/\1/p' | head -1)

if [ -f "$FILE" ]; then
  case "$FILE" in
    *.ts|*.tsx|*.js)
      prettier --write "$FILE" 2>/dev/null
      ;;
    *.py)
      black "$FILE" 2>/dev/null
      ;;
  esac
fi
exit 0

TOKEN_DELTA

Stop

— 回答結束與 Token 統計 (context-tracker.py)

Claude 回答完畢時觸發，計算本輪對話消耗之 Token Delta

Python 實測

這就是專案目錄下的 context-tracker.py 最核心的亮點： 在 UserPromptSubmit 記下「提問前」Token，在 Stop 計算「回答後」Token。 兩者一減，直接在終端機印出：

06-hooks/context-tracker.py 
def handle_stop(data: dict) -> None:
    session_id = data.get("session_id", "unknown")
    transcript_path = data.get("transcript_path", "")

    transcript_content = read_transcript(transcript_path)
    current_tokens = count_tokens_estimate(transcript_content)

    state_file = get_state_file(session_id)
    pre_tokens = 0
    if os.path.exists(state_file):
        with open(state_file, "r") as f:
            pre_tokens = json.load(f).get("pre_tokens", 0)

    delta_tokens = current_tokens - pre_tokens
    print(f"Context: ~{current_tokens:,} tokens, This request: ~{delta_tokens:,} tokens", file=sys.stderr)
